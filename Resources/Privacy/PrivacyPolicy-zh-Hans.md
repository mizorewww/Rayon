# Rayon 隐私政策

_最后更新：2026 年 11 月 27 日_

_本政策的各语言版本如有不一致，以英文版本为准。_

Rayon 是一款 SSH 与服务器客户端。你的服务器、身份、密钥、密码、代码片段、端口转发、文件和终端会话都保存在你自己的设备上；开启 iCloud 同步后，也会保存在你自己的 iCloud 账户中。包括 Rayon 开发者在内，任何人都无法读取这些内容。

Rayon 发送给开发者的数据只有匿名的诊断信息和使用计数。发送多少由你在“设置 › 关于 › 诊断与使用情况”中决定，并且可以随时关闭。

## 1. 各级别发送的内容

- **关闭（0）：**不发送任何内容，Rayon 不会连接遥测服务器。
- **崩溃报告（1）：**来自 Apple MetricKit 的崩溃和卡顿报告，在你的设备上去除所有消息和名称后发送。保留的只有：问题类型、数字形式的异常码和信号码、终止原因的类别、固定列表中的系统异常名称、大致的卡顿时长，以及以二进制 ID 和偏移量表示的、位于 Rayon 和系统中的调用栈。
- **崩溃报告与使用情况（2）：**包含级别 1，另外每天发送一份报告，统计各功能的使用次数，每个数字都归入一个区间（0、1、2–5、6–20、21–100、100 以上）。统计的功能包括：打开的终端会话、文件浏览、文件传输、编辑器、监控、VNC 与 UU 远程会话、运行的代码片段，以及按类型区分的端口转发。报告还统计连接结果（如成功、登录被拒、超时、连接被拒绝、主机密钥未被信任、找不到主机），并标明当天使用过哪些登录方式（密码、密钥、代理）。此外还包括：你的身份中有哪些密钥类型（Ed25519、ECDSA、RSA）、已保存服务器和身份数量所在的区间、是否开启了 iCloud 同步、自定义终端主题和地址隐藏，以及最近 28 天中使用 Rayon 的天数所在的区间。
- **详细诊断（3）：**包含级别 2，另外大约每十天中的一天还会发送：登录耗时的区间、你所监控服务器的操作系统类别（Linux、macOS、BSD、其他），以及 Apple 每日的性能数据（启动时间、卡顿时间、峰值内存、CPU 时间、磁盘写入量），每项都归入区间。

每份报告还包含：Rayon 版本、操作系统的主版本号和次版本号、平台（macOS、iOS 或 iPadOS）、设备类别（Apple 芯片的 Mac、Intel Mac、iPhone 或 iPad）、App 的语言（英文、简体中文、繁体中文或其他）、Rayon 的安装方式（App Store、TestFlight 或直接下载），以及根据你的 App Store 国家或地区得出的粗略地区分组（欧洲经济区/英国/瑞士、中国大陆或其他）。

你可以在“设置 › 关于 › 诊断与使用情况 › 查看发送内容…”中看到确切的报告内容。

## 2. 永远不会发送的内容

无论哪个级别，Rayon 都不会发送：服务器名称、地址、端口或用户名；密码、口令、密钥、密钥指纹或密钥注释；命令、代码片段、终端输入输出或剪贴板；文件名、路径或文件大小；远程横幅或版本字符串；错误信息；环境变量；iCloud 或账户标识符；设备标识符（如 IDFV、IDFA 或序列号）；精确时间、时区、屏幕尺寸、网络类型或 Wi-Fi 名称；以及你的位置。

## 3. 数据如何保存

- 报告中**不含任何**能识别你、你的设备或你这次安装的标识符。每份报告带有一个随机数，仅用于在重复发送时去重，三天内删除。
- 服务器**从不读取或保存你的 IP 地址**和浏览器/User-Agent 字符串，也不保留请求日志。
- 日期只精确到天。每份报告到达后立即计入每日总数，随后丢弃。崩溃和卡顿条目保留 **90 天**用于诊断，然后删除。
- 少于 **10** 份报告的统计格永远不会显示或导出。
- 由于没有任何内容能识别你，报告事后也无法与你关联。这些数据不会用于追踪你，不会出售，除下述处理方外也不会与他人共享。

## 4. 数据处理方

- **Cloudflare, Inc.** 作为 Rayon 的数据处理方运行遥测服务器（Cloudflare Worker 及其位于亚太地区的 D1 数据库）。Cloudflare 的网络在传递连接时必然会看到连接本身，包括其 IP 地址；Rayon 的服务器不会读取它。
- **GitHub, Inc.** 负责响应 Mac 版中的“检查更新…”：只有当你选择这个命令时，Rayon 才会向 GitHub 的公开 API 查询最新版本。GitHub 按其隐私声明处理这次请求。
- **Apple** 提供 MetricKit、iCloud 同步（你的数据位于你自己的 iCloud 账户中）和 App Store，适用 Apple 的隐私政策。
- 你自己让 Rayon 连接的服务，例如你的服务器、Cloudflare Access 或 UU 远程，会按其各自的政策接收你发给它们的内容。

## 5. 更改或撤回你的选择

打开“设置 › 关于 › 诊断与使用情况”并拖动滑块，更改立即生效。降低级别时，本设备上新级别不再发送的待发送报告和计数会被删除；选择“关闭”还会停止 MetricKit 向 Rayon 投递数据，并删除报告队列。“查看发送内容…”中的“删除待发送报告”和“重置使用记录”可以清除其余内容。这个设置分别保存在每台设备上，不会同步。

已经发送的报告无法应要求删除，因为其中没有任何内容能表明它属于谁（GDPR 第 11 条）。

## 6. 法律依据

- **欧洲经济区、英国和瑞士：**你的同意。在你选择“分享匿名数据”之前不会发送任何内容，你也可以随时撤回。
- **中国大陆：**在你看到提示和本政策之前不会发送任何内容。这些数据属于《个人信息保护法》所规定的匿名化信息（第四条、第七十三条）。
- **其他地区：**我们修复问题、改进 Rayon 的正当利益，所用数据在设计上即为匿名。默认级别为 2，首次启动时的提示会告诉你这一点。

Rayon 并非面向儿童，也不会有意收集儿童的数据。

## 7. 联系方式与变更

问题与请求：https://github.com/mizorewww/Rayon/issues

如果 Rayon 发送的内容发生变化，本政策、源代码中的数据结构和 App Store 隐私标签会在同一个版本中一起更新。
