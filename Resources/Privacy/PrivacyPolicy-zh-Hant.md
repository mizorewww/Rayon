# Rayon 隱私權政策

_最後更新：2026 年 11 月 27 日_

Rayon 是一款 SSH 與伺服器用戶端。你的伺服器、身分、金鑰、密碼、程式碼片段、連接埠轉送、檔案和終端機工作階段都儲存在你自己的裝置上；開啟 iCloud 同步後，也會儲存在你自己的 iCloud 帳號中。包括 Rayon 開發者在內，任何人都無法讀取這些內容。

Rayon 傳送給開發者的資料只有匿名的診斷資訊和使用次數。傳送多少由你在「設定 › 關於 › 診斷與使用情況」中決定，並且可以隨時關閉。

## 1. 各等級傳送的內容

- **關閉（0）：**不傳送任何內容，Rayon 不會連線到遙測伺服器。
- **當機報告（1）：**來自 Apple MetricKit 的當機和停頓報告，在你的裝置上移除所有訊息和名稱後傳送。保留的只有：問題類型、數字形式的例外代碼和訊號代碼、終止原因的類別、固定清單中的系統例外名稱、大致的停頓時間，以及以二進位 ID 和位移表示、位於 Rayon 和系統中的呼叫堆疊。
- **當機報告與使用情況（2）：**包含等級 1，另外每天傳送一份報告，統計各功能的使用次數，每個數字都歸入一個區間（0、1、2–5、6–20、21–100、超過 100）。統計的功能包括：開啟的終端機工作階段、檔案瀏覽、檔案傳輸、編輯器、監控、VNC 與 UU 遠端工作階段、執行的程式碼片段，以及依類型區分的連接埠轉送。報告也會統計連線結果（如成功、登入被拒、逾時、連線被拒、主機金鑰未受信任、找不到主機），並標明當天使用過哪些登入方式（密碼、金鑰、代理程式）。此外還包括：你的身分中有哪些金鑰類型（Ed25519、ECDSA、RSA）、已儲存伺服器和身分數量所在的區間、是否開啟 iCloud 同步、自訂終端機主題和地址隱藏，以及最近 28 天中使用 Rayon 的天數所在的區間。
- **詳細診斷（3）：**包含等級 2，另外大約每十天中的一天還會傳送：登入耗時的區間、你所監控伺服器的作業系統類別（Linux、macOS、BSD、其他），以及 Apple 每日的效能資料（啟動時間、停頓時間、記憶體峰值、CPU 時間、磁碟寫入量），每項都歸入區間。

每份報告也包含：Rayon 版本、作業系統的主版本號和次版本號、平台（macOS、iOS 或 iPadOS）、裝置類別（Apple 晶片的 Mac、Intel Mac、iPhone 或 iPad）、App 的語言（英文、簡體中文、繁體中文或其他）、Rayon 的安裝方式（App Store、TestFlight 或直接下載），以及依你的 App Store 國家或地區得出的粗略地區分組（歐洲經濟區/英國/瑞士、中國大陸或其他）。

你可以在「設定 › 關於 › 診斷與使用情況 › 檢視傳送內容…」中看到確切的報告內容。

## 2. 永遠不會傳送的內容

無論哪個等級，Rayon 都不會傳送：伺服器名稱、位址、連接埠或使用者名稱；密碼、密語、金鑰、金鑰指紋或金鑰註解；指令、程式碼片段、終端機輸入輸出或剪貼簿；檔案名稱、路徑或檔案大小；遠端橫幅或版本字串；錯誤訊息；環境變數；iCloud 或帳號識別碼；裝置識別碼（如 IDFV、IDFA 或序號）；精確時間、時區、螢幕尺寸、網路類型或 Wi-Fi 名稱；以及你的位置。

## 3. 資料如何保存

- 報告中**不含任何**能識別你、你的裝置或這次安裝的識別碼。每份報告帶有一個隨機數，只用於在重複傳送時去除重複，三天內刪除。
- 伺服器**從不讀取或儲存你的 IP 位址**和瀏覽器/User-Agent 字串，也不保留請求記錄。
- 日期只精確到天。每份報告到達後立即計入每日總數，隨後丟棄。當機和停頓項目保留 **90 天**用於診斷，然後刪除。
- 少於 **10** 份報告的統計格永遠不會顯示或匯出。
- 由於沒有任何內容能識別你，報告事後也無法與你連結。這些資料不會用於追蹤你，不會出售，除下述處理者外也不會與他人分享。

## 4. 資料處理者

- **Cloudflare, Inc.** 作為 Rayon 的資料處理者執行遙測伺服器（Cloudflare Worker 及其位於亞太地區的 D1 資料庫）。Cloudflare 的網路在傳遞連線時必然會看到連線本身，包括其 IP 位址；Rayon 的伺服器不會讀取它。
- **GitHub, Inc.** 負責回應 Mac 版中的「檢查更新…」：只有當你選擇這個指令時，Rayon 才會向 GitHub 的公開 API 查詢最新版本。GitHub 依其隱私權聲明處理這次請求。
- **Apple** 提供 MetricKit、iCloud 同步（你的資料位於你自己的 iCloud 帳號中）和 App Store，適用 Apple 的隱私權政策。
- 你自己讓 Rayon 連線的服務，例如你的伺服器、Cloudflare Access 或 UU 遠端，會依其各自的政策接收你傳給它們的內容。

## 5. 變更或撤回你的選擇

開啟「設定 › 關於 › 診斷與使用情況」並拖動滑桿，變更立即生效。調低等級時，本裝置上新等級不再傳送的待傳送報告和計數會被刪除；選擇「關閉」還會停止 MetricKit 向 Rayon 遞送資料，並刪除報告佇列。「檢視傳送內容…」中的「刪除待傳送報告」和「重設使用記錄」可以清除其餘內容。這個設定分別保存在每台裝置上，不會同步。

已經傳送的報告無法依請求刪除，因為其中沒有任何內容能表明它屬於誰（GDPR 第 11 條）。

## 6. 法律依據

- **歐洲經濟區、英國和瑞士：**你的同意。在你選擇「分享匿名資料」之前不會傳送任何內容，你也可以隨時撤回。
- **中國大陸：**在你看到提示和本政策之前不會傳送任何內容。這些資料屬於《個人資訊保護法》所規定的匿名化資訊（第四條、第七十三條）。
- **其他地區：**我們修正問題、改進 Rayon 的正當利益，所用資料在設計上即為匿名。預設等級為 2，首次啟動時的提示會告訴你這一點。

Rayon 並非以兒童為對象，也不會有意收集兒童的資料。

## 7. 聯絡方式與變更

問題與請求：https://github.com/mizorewww/Rayon/issues

如果 Rayon 傳送的內容有所變化，本政策、原始碼中的資料結構和 App Store 隱私權標籤會在同一個版本中一起更新。
