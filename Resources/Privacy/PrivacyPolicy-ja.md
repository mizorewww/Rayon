# Rayon プライバシーポリシー

_最終更新日：2026 年 11 月 28 日_

_本ポリシーの各言語版の内容に相違がある場合は、英語版が優先します。_

Rayon は SSH およびサーバーのクライアントです。お使いのサーバー、ID、鍵、パスワード、スニペット、ポートフォワード、ファイル、ターミナルセッションは、お使いのデバイス上に保存され、iCloud 同期をオンにした場合はご自身の iCloud アカウントにも保存されます。Rayon の開発者を含め、ほかの誰もこれらを読むことはできません。

Rayon が開発者に送信するデータは、匿名の診断情報と使用回数だけです。どこまで送信するかは「設定 › 情報 › 診断と使用状況」で選ぶことができ、いつでもオフにできます。

## 1. 各レベルで送信される内容

- **オフ（0）：** 何も送信しません。Rayon はテレメトリサーバーに一切接続しません。
- **クラッシュレポート（1）：** Apple の MetricKit によるクラッシュおよびハングのレポートで、すべてのメッセージと名前をデバイス上で取り除いたものです。残るのは、問題の種類、数値の例外コードとシグナルコード、終了理由のカテゴリ、固定リストに含まれるシステム例外名、おおよそのハング時間、そして Rayon およびシステム内のバイナリ ID とオフセットで表したコールスタックです。
- **クラッシュレポートと使用状況（2）：** レベル 1 に加えて、1 日に 1 件、機能の使用回数のレポートを送信します。各回数は範囲（0、1、2〜5、6〜20、21〜100、100 超）に丸められます。数える機能は、開いたターミナルセッション、開いたファイルブラウザ、ファイル転送、エディタ、モニター、VNC および UU Remote のセッション、実行したスニペット、種類別のポートフォワードです。レポートには接続結果（成功、サインイン拒否、タイムアウト、接続拒否、ホスト鍵が信頼されていない、ホストが見つからない など）の回数と、その日に使われたサインイン方法（パスワード、鍵、エージェント）も含まれます。さらに、お使いの ID に含まれる鍵の種類（Ed25519、ECDSA、RSA）、保存されたサーバーおよび ID の数の範囲、iCloud 同期・カスタムのターミナルテーマ・アドレスの非表示がオンかどうか、そして直近 28 日間に Rayon を使用した日数の範囲も含まれます。
- **詳細な診断（3）：** レベル 2 に加えて、およそ 10 日に 1 日、サインインにかかった時間の範囲、監視しているサーバーのオペレーティングシステムの系統（Linux、macOS、BSD、その他）、そして Apple の日次パフォーマンス指標（起動時間、ハング時間、ピークメモリ、CPU 時間、ディスク書き込み量）を、それぞれ範囲に丸めて送信します。

すべてのレポートには、Rayon のバージョン、オペレーティングシステムのメジャーバージョンとマイナーバージョン、プラットフォーム（macOS、iOS または iPadOS）、デバイスの種類（Apple シリコン搭載の Mac、Intel Mac、iPhone または iPad）、App の言語（英語、簡体字中国語、繁体字中国語、日本語、フランス語、スペイン語、またはその他）、Rayon のインストール方法（App Store、TestFlight、または直接ダウンロード）、そして App Store の国または地域から得た大まかな地域グループ（EEA／英国／スイス、中国本土、またはその他）も含まれます。

実際のレポートは「設定 › 情報 › 診断と使用状況 › 送信内容を表示…」で確認できます。

## 2. 決して送信されないもの

どのレベルでも、Rayon は次のものを決して送信しません：サーバーの名前、アドレス、ポート、ユーザー名；パスワード、パスフレーズ、鍵、鍵のフィンガープリント、鍵のコメント；コマンド、スニペット、ターミナルの入出力、クリップボード；ファイル名、パス、ファイルサイズ；リモートのバナーやバージョン文字列；エラーメッセージ；環境変数；iCloud やアカウントの識別子；デバイスの識別子（IDFV、IDFA、シリアル番号など）；正確な時刻、タイムゾーン、画面サイズ、ネットワークの種類、Wi-Fi の名前；お客様の位置情報。

## 3. データの保管方法

- レポートには、お客様、お使いのデバイス、またはこのインストールを識別する**識別子は一切含まれません**。各レポートには、二重に送信された場合に重複を取り除くためだけに使うランダムな数値が付いており、3 日以内に削除されます。
- サーバーは**お客様の IP アドレス**やブラウザ／User-Agent 文字列を**読み取ることも保存することもなく**、リクエストログも残しません。
- 日付は日単位でのみ保持されます。各レポートは届いた時点で日次の合計に加算され、その後破棄されます。クラッシュおよびハングの項目は診断のために **90 日間**保持され、その後削除されます。
- レポート数が **10** 件未満の合計は、表示もエクスポートもされません。
- お客様を識別するものが何もないため、レポートを後からお客様に結び付けることはできません。このデータはお客様の追跡に使われることはなく、販売されることもなく、下記の処理者以外と共有されることもありません。

## 4. データを処理する者

- **Cloudflare, Inc.** は、Rayon の処理者としてテレメトリサーバー（Cloudflare Worker と、アジア太平洋地域にあるその D1 データベース）を運用しています。Cloudflare のネットワークは、接続を届ける過程で、その IP アドレスを含む接続自体を必然的に目にしますが、Rayon のサーバーはそれを読み取りません。
- **GitHub, Inc.** は、Mac 版 App の「アップデートを確認…」に応答します。この機能は、お客様がこのコマンドを選んだときにのみ、GitHub の公開 API に最新リリースを問い合わせます。GitHub はこのリクエストを自社のプライバシーに関する声明に従って扱います。
- **Apple** は、MetricKit、iCloud 同期（お客様のデータはご自身の iCloud アカウント内にあります）、および App Store を、Apple のプライバシーポリシーに基づいて提供します。
- お客様のサーバー、Cloudflare Access、UU Remote など、お客様ご自身が Rayon を接続するサービスは、お客様が送信したものをそれぞれのポリシーに従って受け取ります。

## 5. 選択の変更または撤回

「設定 › 情報 › 診断と使用状況」を開き、スライダーを動かしてください。変更はすぐに反映されます。レベルを下げると、新しいレベルでは送信されない、送信待ちのレポートと回数がこのデバイス上で削除されます。「オフ」にすると、Rayon への MetricKit の配信も停止され、レポートのキューが削除されます。残りの内容は「送信内容を表示…」の「保留中のレポートを削除」と「アクティビティ履歴をリセット」で消去できます。この設定はデバイスごとに保持され、同期されることはありません。

すでに送信されたレポートは、それが誰のものかを示す情報が何も含まれていないため、要求に応じて削除することはできません（GDPR 第 11 条）。

## 6. 法的根拠

- **EEA、英国およびスイス：** お客様の同意。お客様が「匿名データを共有」を選ぶまで何も送信されず、いつでも同意を撤回できます。
- **中国本土：** お客様が通知と本ポリシーを確認するまで何も送信されません。このデータは、中華人民共和国個人情報保護法（第 4 条、第 73 条）に定める匿名化された情報です。
- **その他の地域：** 設計上匿名であるデータを用いて、バグを修正し Rayon を改善するという当方の正当な利益。デフォルトはレベル 2 であり、初回起動時の通知でその旨をお知らせします。

Rayon は子どもを対象としたものではなく、子どもからデータを故意に収集することはありません。
