Terminal settings data for Rayon

settings.json (every Ghostty option's name, description, default and input
type) and keybindings.json (Ghostty's keybinding actions) are derived from
https://github.com/zerebos/ghostty-config

Rayon's changes: the registry is reduced to data (no web widgets or icons),
the macOS default for quit-after-last-window-closed is corrected, and theme
names are dropped from it; themes come from GhosttyTheme (libghostty-spm).

themes.json holds the color themes of Ghostty's iTerm2-Color-Schemes
collection that GhosttyTheme does not ship, so no theme offered before is
lost. Theme names retain their original attribution. Color theme license text
is included in Themes-LICENSE.txt (MIT).
